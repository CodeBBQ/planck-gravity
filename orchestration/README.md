# Coordination layer — architectural illustration

This section records the **conceptual** distinction between research coordination and the six specialist scientific responsibilities.

In a multi-role research setting, the coordinator organizes questions and identifies when external scientific verification is needed. The scientific content must still be supported by sources, reproducible calculations and critical review.

The public repository intentionally contains **no** operational campaign registry, executable moderator instructions, worker prompts, scheduling contract or session-acceptance procedure.

Read the [coordination overview](../ORCHESTRATION_MODEL.md), [role descriptions](../agents/README.md) and [readiness statement](../RESEARCH_READINESS.md). **NO-GO** is not evidence of failed physics; it means the complete live system has not passed independent acceptance.
